# Примитивная база данных

Учебный проект: консольная база данных на Python. Поддерживает создание и
удаление таблиц с типизированными столбцами (`int`, `str`, `bool`), CRUD-операции
с записями, подтверждение опасных действий и централизованную обработку ошибок.
Метаданные таблиц хранятся в `db_meta.json`, данные — в `data/<имя_таблицы>.json`.

## Установка и запуск

Нужны Python 3.12+ и [uv](https://docs.astral.sh/uv/).

```bash
make install   # установить зависимости (uv sync)
make run       # запустить базу данных (uv run database)
make lint      # проверить код линтером ruff
```

Сборка и установка пакета, после которой в терминале доступна команда `database`:

```bash
make build            # uv build
make package-install  # uv tool install dist/*.whl
database
```

## Управление таблицами

Команды:

* `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать таблицу.
  Столбец `ID:int` добавляется автоматически.
* `list_tables` — показать список всех таблиц.
* `drop_table <имя_таблицы>` — удалить таблицу.
* `help` — показать справку.
* `exit` — выйти.

Поддерживаемые типы данных: `int`, `str`, `bool`.

Пример использования:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
```

## CRUD-операции

Данные каждой таблицы хранятся в отдельном файле `data/<имя_таблицы>.json`.

Команды:

* `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — создать запись.
  Значение `ID` не передается, оно генерируется автоматически.
* `select from <имя_таблицы>` — прочитать все записи.
* `select from <имя_таблицы> where <столбец> = <значение>` — прочитать записи по условию.
* `update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>` — обновить запись.
* `delete from <имя_таблицы> where <столбец> = <значение>` — удалить запись.
* `info <имя_таблицы>` — вывести информацию о таблице.

Строковые значения записываются в кавычках (`"Sergei"`), логические — `true`/`false`,
целые числа — без кавычек. Все поля обязательны.

Пример использования:

```text
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Декораторы и обработка ошибок

Модуль `decorators.py` содержит:

* `handle_db_errors` — централизованно перехватывает `KeyError` (нет таблицы
  или столбца), `ValueError` (ошибка валидации) и `FileNotFoundError` и выводит
  понятное сообщение вместо падения программы.
* `confirm_action(action_name)` — запрашивает подтверждение опасных операций
  (`drop_table`, `delete`). Операция выполняется только при ответе `y`.
* `log_time` — выводит время выполнения `insert` и `select`.
* `create_cacher()` — замыкание, кэширующее результаты одинаковых запросов `select`.

Пример:

```text
>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: n
Операция отменена.
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
>>>Введите команду: select from users
Ошибка: Таблица "users" не существует.
```
